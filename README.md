# 建工计算器

版本：V1.5  
作者：五羊咩咩成  
联系作者：2136408486@qq.com

一个面向建筑工程、工程测量、管材计算和单位换算场景的静态网站。项目使用 React + TypeScript + Vite 开发，数据来源严格绑定到用户提供的 PRD 和三份资料文档。

## 功能

- 首页：仅保留主标题“建工计算器”，下方四个主入口：计算器、管材计算、工程测量计算、单位换算。
- 关于页：名称、版本 V1.5、作者、邮箱、所有公式数据来源入口。
- 计算器：普通计算、科学计算、度分秒模式；表达式解析不使用 `eval`；历史记录写入 `localStorage`。
- 工程测量计算：接入第一部分资料中的 23 个计算项，包含公式说明、来源、状态与图例说明区域。
- 管材计算：按第二部分修正版实现到无缝钢管为止，含塑料管材选用表、材料密度表、自定义密度，不做查表法。
- 单位换算：长度、体积、面积、重量/质量、压强、角度、力、时间、能量、密度。
- UI：亮色/暗色主题切换并本地保存，iOS 毛玻璃卡片和按钮，轻量动态科技背景。

## 资料接入原则

源码中的结构化数据位于：

- `src/data/survey.ts`
- `src/data/pipes.ts`
- `src/data/units.ts`
- `src/data/sources.ts`

每个计算项或单位类别都绑定 `sourceIds` 和 `status`。资料中标注“需复核”的项目不会伪装成已核对，页面会显示警示。

当前显式保留的复核项：

- 工程测量：方位角推算、支导线、中线逐桩、涵洞放样、部分交会定点方向约定。
- 管材：PVC-U 10Mpa / 12.5Mpa 名称、不锈钢 201 密度、镀锌层重量系数 `c`。
- 单位换算：力单位 MN/mN 冲突、能量类别未见截图、市制单位和年等默认约定。

## 测试与验收

```bash
npm run test
npm run build
```

测试覆盖：

- 单位换算通用公式。
- 管材圆管、方管、矩形管、平椭圆管。
- 工程测量方位角、坐标反算、点到线距离。
- 计算器表达式解析和 DMS 转换。

人工验收建议：

- 首页只显示“建工计算器”主标题和四个入口。
- 切换亮色/暗色主题后刷新页面，主题保持不变。
- 计算器输入 `2+3*4`，结果应为 `14`；科学模式 `sin(30)` 在角度模式下应为 `0.5`。
- 管材计算选择 PE 管，默认参数可输出理论重量、截面面积、总重量和来源。
- 工程测量任意计算项应显示输入表单、公式说明、SVG 图例、来源和状态。
- 单位换算 `10 ft -> m` 应输出 `3.048 m`。
- 来源页可搜索，并能按模块查看“已核对/需复核”状态。

## 部署到 GitHub Pages

项目内已提供 `.github/workflows/deploy.yml`。

1. 将源码推送到 GitHub 仓库。
2. 在仓库 Settings -> Pages 中选择 GitHub Actions。
3. 推送到 `main` 分支后，workflow 会执行 `npm ci`、`npm run build`，并发布 `dist`。

GitHub Actions 会自动使用仓库名作为 `base` 路径。手动构建到子路径时可指定：

```bash
VITE_BASE_PATH="/你的仓库名/" npm run build
```
